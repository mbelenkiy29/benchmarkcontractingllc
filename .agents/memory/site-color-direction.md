---
name: Site color direction
description: The approved color hierarchy for Benchmark Contracting Group pages and future UI work.
---

Use true neutral blacks, whites, and grays for page backgrounds, typography, icons, labels, borders, links, and decorative accents. Avoid cool grays that read as navy or blue.

Reserve the brand orange for primary action buttons and their interactive states rather than repeating it throughout page content.

**Why:** The user wants a modern luxury presentation and felt the prior blue-toned grays and frequent orange accents made the site look less refined.

**How to apply:** For new or revised UI, use the neutral Tailwind palette rather than the cool gray palette. Use the primary orange token only for prominent conversion actions such as estimate, quote, contact, or submit buttons.
